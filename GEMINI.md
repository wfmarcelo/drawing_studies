# Project Overview
This repository, "Estudos de Desenho" (Drawing Studies), serves as a structured archive for personal art practice and learning. It organizes various drawing materials, exercises, and projects based on books, courses, and tutorials.

# Directory Structure
- `books/`: Contains source files (`.kra`, `.svg`) for exercises based on drawing textbooks (Loomis, Norling, Reyna).
- `courses/`: Houses study materials and practice files for structured courses (Famous Artists Illustration Course, Blender 3D).
- `exports/`: A collection of exported images (`.webp`, `.png`, `.jpg`) representing completed study sessions or specific exercises.
- `practice/`: Miscellaneous practice files.
- `tutorials/`: Source files for tutorials, specifically focused on vector illustration (e.g., Logos by Nick).

# Usage
- The directory is primarily an organizational structure for tracking progress through various artistic learning resources.
- Source files are primarily in Krita format (`.kra`), Blender format (`.blend`), and vector formats (`.svg`).
- Exports are maintained in the `exports/` folder, usually named with a date prefix (YYYY_MM_DD) for tracking history.
